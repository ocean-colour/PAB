# Image credits

## `pace_ocean_color.jpg`

Real PACE/OCI ocean-color imagery showing a phytoplankton bloom (turquoise
swirls) in the Black Sea, with the Aegean and eastern Mediterranean below.
Used as the "what PACE sees" inset in the PAB summary graphic
(`docs/scripts/pab_graphic.py`).

- **Source:** NASA SVS / Wikimedia Commons — "PACE Observes Namesake Plankton,
  Aerosols, Clouds and Ocean Ecosystem" (SVS31294, PACE/OCI, 2024-06-01).
- **License:** Public domain (NASA).
- **Processing:** downscaled to 1600 px wide and saved as JPEG for repo size.
